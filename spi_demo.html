SCLK / CS / MOSI / MISO 总线电平波形
标准帧结构说明
  • • CS 片选：低电平有效，拉低启动传输，拉高结束传输
  • • SCLK 时钟：由主机驱动，CPOL 决定空闲电平，CPHA 决定采样边沿
  • • MOSI：主机输出、从机输入，数据方向 主机 → 从机
  • • MISO：从机输出、主机输入，数据方向 从机 → 主机
  • • 全双工：同一时钟沿下，MOSI 与 MISO 同时传输，双向独立
  • • 数据位：MSB 高位优先，在一个边沿切换，另一个边沿采样
  • • 模式0：CPOL=0 空闲低，CPHA=0 第一个边沿采样
